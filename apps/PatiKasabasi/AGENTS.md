# Geliştirme Talimatları

- `PROJECT_CONTEXT.md` ve `SESSION.md` authoritative belgeleridir.
- iPad 1 / iOS 5.1.1 / armv7 / 256 MB / non-ARC sınırlarından sapma.
- Swift, ARC, Auto Layout, Storyboard, SpriteKit, Metal, SceneKit veya modern API ekleme.
- Mevcut MRC sahiplik kurallarını koru.
- Fiziksel cihazda doğrulanmamış özelliği çalışıyor kabul etme.
- Büyük bitmap, sürekli timer ve açık dünya simülasyonu ekleme.
- Çocuk güvenliği ilkelerini GAME_DESIGN.md ile uyumlu tut.
